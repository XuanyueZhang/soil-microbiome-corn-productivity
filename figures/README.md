# Figures

This folder contains study-design and workflow figures for the **Soil Microbiome and Corn Productivity** project.

## Current Figures

- `soil_microbiome_workflow_diagram.png` — overview of the proposed multi-omics workflow from field sampling through predictive modeling.
- `study_design_overview.png` — summary of the field design, sampling schedule, data types, and integration framework.

## Figure Purpose

These figures are included to make the project easier to understand visually and to highlight the experimental design and bioinformatics workflow for this study-design portfolio project.
